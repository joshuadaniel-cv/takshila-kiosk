# Takshila Library Kiosk

Self-service library kiosk (PWA) for the Takshila Library iPad:
Find a Book, Borrow or Return (both embed Libib), and calm Music.

- Live: https://home.takshila.online
- Install: open in Safari on the iPad -> Share -> Add to Home Screen, then turn on Guided Access.

Static site served by GitHub Pages. Content (Libib, Spotify, YouTube) loads live.
